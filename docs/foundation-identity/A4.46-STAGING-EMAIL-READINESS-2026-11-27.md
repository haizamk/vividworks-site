## 6. Recommended staging email configuration approach

1. **Choose one transport for staging** (architecture mentions transactional providers such as **Resend/SES**; standard **`smtp`** is also supported by `config/mail.php`).
2. **Set Coolify/host environment variables only** (no commits): at minimum `MAIL_MAILER=smtp`, `MAIL_HOST`, `MAIL_PORT`, `MAIL_USERNAME`, `MAIL_PASSWORD`, and `MAIL_SCHEME` (`tls` / `smtp` as required by provider). Set `MAIL_FROM_ADDRESS` and `MAIL_FROM_NAME` to the approved staging sender identity.
3. **Reload PHP-FPM / redeploy** so FPM workers pick up env (read-only verification can repeat the A4.46 bootstrap presence check).
4. **Keep `MAIL_MAILER=log` only for local/CI**; staging should not use `log` for D-EMAIL-V proof.
5. **Production SMTP remains out of scope** for staging I1 entry (per I0 closure).
